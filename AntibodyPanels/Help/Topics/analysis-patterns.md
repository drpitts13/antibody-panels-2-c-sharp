# Pattern Matches

Pattern Matches compares the reaction pattern with the antigen pattern for each candidate.

- **Antibody** is the specificity.
- **Matches** counts cells where the reaction and the antigen agree: the cell has the antigen and reacted, or lacks the antigen and did not react.
- **Mismatches** counts cells where they disagree.
- **Confidence** summarizes how clean that match is.

A high match count with few mismatches supports a single specificity. Mismatches are the cells you should read on **Suspected Antibodies** under conflicting or unexplained reactions.

This tab does not rule antibodies out and it does not confirm an identification. Use it beside the score and the rule-out count when you are deciding whether one antibody explains the panel.
